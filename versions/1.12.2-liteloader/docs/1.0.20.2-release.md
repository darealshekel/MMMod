# MMMod 1.0.20.2 - Minecraft 1.12.2 LiteLoader

- Fixed the startup crash when Forge and LiteLoader are installed together.
- Preserved compatibility with LiteLoader-only installations.
- Includes the existing 1.12.2 reliability fixes for confirmed block counting, session saving/recovery, account-owned session history, and hourly statistics.

Thanks to @useleess for the Forge compatibility fix in [PR #21](https://github.com/darealshekel/MMMod/pull/21).

Install `mmm-1.0.20.2+1.12.2-liteloader.litemod` in your Minecraft 1.12.2 LiteLoader mods folder, replacing the previous MMM file. Forge is optional. This is not a Fabric or Ornithe build, and it does not include the full 1.0.21 feature/fix backport.

Back up MMM settings and history before updating from old shared-storage builds. No website deployment or sync-access policy change is included.

## Verification

The final release passed 408 tests (2 optional tests skipped), Java 8 artifact checks, and isolated production-loader startup checks with Forge 14.23.5.2859 plus LiteLoader and with LiteLoader alone. These checks do not certify every modpack or authenticated multiplayer interaction.

The release includes matching source, checksums, and rebuild materials for the bundled compatibility libraries.
