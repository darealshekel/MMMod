# MMMod 1.0.23: Settings and Collections

- **Settings:** Search for a setting, jump straight to Hotkeys or Website Link, and open session tools from one place. On 1.21.1, 1.21.4 and 1.21.6, Settings opens to Everyday and shows each category's controls without another click.
- **Collections:** Click the book button in your inventory to see block progress and earned tiers. Filters are remembered, and inspecting another tier no longer changes the milestone you are tracking.
- **Mining HUD (1.21 and 1.21.11):** See the block you are mining, progress to its next milestone and your rank when available. The overlay stays visible while you mine, fades when you stop, and can be moved and resized in Move HUD. Achievement and collection milestones also have on-screen cards.
- The color picker is sharper across GUI scales. Perimeter Timelapse is no longer included.

Replace the previous MMMod file with the one for your exact Minecraft version. Use the `.litemod` for 1.12.2 with LiteLoader, with or without Forge. All other downloads are Fabric jars. There is no separate core mod to install.
