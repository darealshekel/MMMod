# MMMod 1.0.22

MMMod now uses shared code across all supported versions, making future fixes easier to maintain and test consistently.

- Moved duplicated logic and tests into a shared core, with separate Minecraft/loader adapters.
- Kept each version's existing features, saved data and installation process.
- Added a full build/test matrix for the supported versions.
- Preserved the 1.12.2 Forge + LiteLoader compatibility fix.

Download the file matching your Minecraft version and replace the previous MMM file. No extra core mod is required.

Supported: 1.12.2 LiteLoader, and Fabric 1.17.1, 1.19.4, 1.20.1, 1.21, 1.21.1, 1.21.4, 1.21.6, 1.21.11, 26.1.2, 26.2 and 26.3.

This is an internal refactor, not a promise that every older Minecraft version has the same features as 1.21. It introduces no new sync-access or game-mode rules.

Verification: all twelve builds and regression suites passed; the independent core and migration-tool tests passed. Nine versions passed their existing isolated gameplay harnesses. 1.12.2 (with and without Forge), 1.17.1 and 26.1.2 received startup checks rather than full gameplay harness coverage. Authenticated production sync and arbitrary third-party modpacks were not tested. See `docs/1.0.22-verification.md` in the source for details.

The source ZIP contains the whole shared repository. Keep its folders together when rebuilding. The 1.12.2 rebuild ZIP supplies unshaded mod classes, compatibility-library sources and licenses; it is not an installable mod.
