# MMMod 1.0.23 release checks

The release covers all twelve clients in `versions.json`. The release manifest records the Minecraft version, loader, exact filename, SHA-256, test count, failures, errors and skips for each download. A successful compile is not a packaged-client pass.

## What the checks cover

- **Every client:** compile and test the wrapper, check archive metadata and entrypoints, and launch the actual distribution file in an isolated game directory. The release gate compares its SHA-256 to the packaged-client receipt before staging it.
- **Fabric:** open Settings and Collections. At wide and compact GUI sizes, exercise header shortcuts, Tools destinations and their return paths. Open the secondary editors and check the rendered color picker. Minecraft 1.21.1, 1.21.4 and 1.21.6 use the `visible-rail-v4` checks for Everyday, inline settings, category switching and search. Other Fabric versions use `visible-tools-v3`.
- **Minecraft 1.12.2:** check the final Java 8-compatible LiteMod in LiteLoader alone and LiteLoader with Forge. Verify both mappings, the Settings and Collections routes, and the secondary editors.
- **Distribution:** produce the matching source archive and LiteLoader rebuild inputs from the release commit. Publish the checksums alongside the downloads. The ZIPs are for developers; players install one matching JAR or LiteMod.

These checks do not certify arbitrary multiplayer servers or modpacks. Optional live-service tests can be skipped and are recorded as skips, not passes. The 26.x checks verify Share is disabled outside a world, not that in-world sharing succeeds.

## Reproduce

1. Install Pillow (`python -m pip install Pillow==12.2.0`) for the screenshot checks. Run `node tools/check-layout.mjs`, `node --test tools/tests/*.test.mjs`, `python -B -m unittest discover -s tools/tests` and the standalone Gradle tests in `core/`.
2. Run the wrapper's tests and build with the toolchain in the README. Use `releaseLiteMod` for 1.12.2. Do not substitute smoke, development or sources jars.
3. On Fabric run `python tools/verify-packaged-fabric.py <wrapper-id> --ui --sha256 <hash>`. For LiteLoader use `versions/1.12.2-liteloader/tools/verify-packaged-boards.ps1` for both supported modes.
4. Run `python tools/audit-packaged-ui.py --write-report`, then `python tools/stage-feature-release.py --stage`. Package the matching source and LiteLoader rebuild inputs with `tools/package-companions.py`.

For the LiteLoader rebuild ZIP, copy the four library source and license files from the [1.0.22 rebuild ZIP](https://github.com/darealshekel/MMMod/releases/download/v1.0.22/mmm-1.0.22%2B1.12.2-liteloader-rebuild.zip) to `release-artifacts/1.0.22/rebuild/`. The packager checks each against its pinned SHA-256; do not substitute the previous release's dev jar for the current one.
