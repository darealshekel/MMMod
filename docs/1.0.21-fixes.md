## MMMod 1.0.21 - Minecraft 1.21 Reliability Fixes

- Fixed queued syncs overwriting each other and newer updates being lost after a failed request.
- Separated personal mining totals and records between Minecraft accounts.
- Fixed paused/restored sessions affecting timer and hourly stats, and delayed timer completion screens.
- Improved MMM chat typing, reconnects, and advancement notification retries.
- Fixed lifetime streak retention and block ESP rendering on affected versions.
- Improved live rank and collection estimates so unrelated website changes do not erase new local mining.
- Reduced sync-time disk reads and improved saving during shutdown.

This release is for Minecraft 1.21 with Fabric. Sync access and website approval rules are unchanged.

Replace the old MMM jar in your Minecraft 1.21 instance. Other Minecraft versions are not included in this release.

Legacy personal data without a saved owner is preserved for recovery rather than assigned to a different Minecraft account. Old estimates without world receipts retain their migration behavior; newly recorded mining uses world-scoped sync receipts.
