# MMMod 1.0.23 Hotfix 1

- **Settings** now opens directly to **Everyday settings** on all 12 supported Minecraft versions. Select a category to edit its settings immediately. Hotkeys and Website Link remain in the header.
- **Minecraft 1.12.2:** compact Settings pages no longer skip controls. Arrow keys navigate the Tools grid and follow the selected tool across pages.

Download the file for your exact Minecraft version. Install the `.litemod` for 1.12.2 with LiteLoader (with or without Forge); all other versions use Fabric jars. Replace your existing file, even if it already says 1.0.23: this hotfix keeps the same in-game version and filenames.

All 12 downloads passed in-game Settings checks at wide and compact window sizes. SHA-256 checksums and the per-version manifest are attached. The source and rebuild ZIPs are for developers, not for your mods folder.
