# MMMod 1.0.20 - Minecraft 26.2

- Brings the latest 1.0.20 features to Minecraft 26.2.
- Browse MMM and block leaderboards in-game, or use a leaderboard as your sidebar.
- Track collections with live progress, updated tiers, red/green completion panes, and HUD pins.
- See collection rank and Top % from synced website rankings.
- Share collection milestones in MMM Chat without repeating them after sync.
- Live rank-overtake estimates, mining efficiency in Session Summary, and clickable update notices.
- Includes MMM advancements, chat tools, HUD, sessions, scoreboard tools, and optional website sync.

Requires Minecraft 26.2, Java 25, and Fabric Loader 0.19.3 or newer. Fabric API is included; Mod Menu is optional. Open settings with X + V.

Collection rankings use synced website data. Combined and local-only collections show when ranking is unavailable. Website sync remains off by default.
